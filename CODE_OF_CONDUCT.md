# Code of Conduct

Mnemos IDE has adopted the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project: in issues, pull
requests, discussions and any other project space, and when representing the project elsewhere.

In short: be respectful and constructive, assume good faith, and keep criticism about the work,
not the person. Harassment, insults and personal attacks are not tolerated.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers privately at
**mnemos@twincurrent.dk** (put "Conduct" in the subject). Reports are read by the maintainers only and handled
confidentially. If a report concerns one of the maintainers, say so and it will be handled by
the other.

The maintainers decide on consequences following the
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
of the Contributor Covenant, from a private warning up to a permanent ban from the project.
